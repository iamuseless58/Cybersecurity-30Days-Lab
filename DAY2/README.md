Project Description

This project scans devices connected to the local network using Python and Nmap.

The scanner identifies active hosts within the target IP range.

Example target:
192.168.1.0/24

 Red Team Concept

->Reconnaissance.

Attackers first identify active systems before launching attacks.

Purple Team Concept

-> Network Visibility and Monitoring.

Defenders monitor unknown devices and suspicious scans.
